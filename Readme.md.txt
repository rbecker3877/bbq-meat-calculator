# 🔥 BBQ Meat Calculator
Accurate, stress‑free planning for any BBQ event — from backyard cooks to big gatherings.

This tool helps you calculate:
- Meat quantities per person
- Cook times based on cut and weight
- Resting times
- Total timeline planning
- Fuel estimates (charcoal, wood, pellets)

All in a clean, mobile‑friendly interface with multiple themes (Light, Dark, Woodgrain).
